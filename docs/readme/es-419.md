# Pascoal

> Un IDE moderno de Pascal para escritorio - escribe, compila y ejecuta programas Pascal.

[English](../../README.md) · [Português (BR)](pt-BR.md) · [Polski](pl.md)

---

## ¿Qué es Pascoal?

Pascoal es un IDE ligero de Pascal para escritorio, construido con Tauri, Rust,
Svelte, TypeScript y CodeMirror.

Su enfoque es ofrecer una interfaz moderna, compilación real con Free Pascal,
ejecución interactiva de programas, navegación de proyectos y una experiencia de
desarrollo adecuada tanto para estudiantes como para desarrolladores de Pascal.

## Descarga

Descarga la versión más reciente desde la
[página de Releases](https://github.com/brener-fregulia/Pascoal/releases/latest).

- **Windows** - `Pascoal_x.x.x_x64-setup.exe`
- **Linux** - `.deb`, `.rpm` o `.AppImage`

> **Windows SmartScreen:** Pascoal todavía no cuenta con firma de código, por lo
> que Windows puede mostrar una advertencia de SmartScreen en la primera ejecución.

## Funcionalidades

- Editor CodeMirror 6 con resaltado estructural de Pascal basado en Tree-sitter
- Integración con Free Pascal Compiler (FPC)
- Consola interactiva para programas con soporte para `readln`
- Edición en múltiples pestañas
- Explorador de archivos con operaciones sobre archivos y carpetas
- Buscar/reemplazar y búsqueda entre archivos
- Instalación guiada de FPC
- Actualizaciones automáticas de la aplicación
- Notas de versión e historial de versiones dentro de la aplicación
- Menús Archivo, Editar y Ayuda con estilo nativo
- Configuración de apariencia, idioma, identidad de Git y estado del toolchain
- Temas Dark, Light y Charcoal
- Interfaz en English, Português (BR), Español (Latinoamérica) y Polski
- Soporte para Windows y Linux

## Requisitos

Para desarrollo:

- [Rust](https://rustup.rs/) stable
- [Node.js](https://nodejs.org/) 22 o una versión más reciente
- [Requisitos previos de Tauri](https://tauri.app/start/prerequisites/) para tu plataforma

No es necesario tener FPC instalado previamente para el uso normal; Pascoal puede
detectar la ausencia del compilador y guiar su instalación.

## Primeros pasos

```bash
git clone https://github.com/brener-fregulia/Pascoal.git
cd Pascoal
npm install
cargo tauri dev
```

Build de producción:

```bash
cargo tauri build
```

Desarrollo solo del frontend:

```bash
npm run dev:ide
```

## Pruebas

## Stack tecnológica

| | |
|---|---|
| Runtime | Tauri 2 |
| Backend | Rust |
| Frontend | Svelte 5 + Vite + TypeScript |
| Compilador | Free Pascal (FPC) |
| Editor | CodeMirror 6 |
| Consola | xterm.js |
| Control de versiones | Git |
| Pruebas | Vitest + cargo test |
